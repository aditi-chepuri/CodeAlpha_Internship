## 🌸 Task 1: Iris Flower Classification

A Machine Learning classification project that predicts the species of 
an Iris flower based on its sepal and petal measurements.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

#### Machine Learning Algorithm

- Logistic Regression

#### Project Workflow

1. Load the Iris dataset using Scikit-learn.
2. Explore the dataset and its features.
3. Split the data into training and testing sets.
4. Train a Logistic Regression model.
5. Predict Iris flower species.
6. Evaluate the model using accuracy and classification metrics.
7. Generate a confusion matrix.
8. Visualize relationships between the features using a pairplot.
9. Test the model with a sample flower measurement.

#### Classes

- Setosa
- Versicolor
- Virginica

### 📊 Task 2: Unemployment Analysis with Python

A Data Analysis project that explores unemployment trends in India using Python. The project analyzes regional variations, rural and urban unemployment, monthly trends, and changes between 2019 and 2020.

#### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

#### Project Workflow

1. Load the unemployment datasets.
2. Explore the dataset structure.
3. Check missing values and data types.
4. Clean the datasets.
5. Analyze the overall unemployment trend.
6. Analyze state and regional unemployment.
7. Compare rural and urban unemployment.
8. Analyze monthly unemployment trends.
9. Compare unemployment rates between 2019 and 2020.
10. Analyze employment and labour participation.
11. Perform correlation analysis.
12. Visualize important findings.

#### Key Dataset Finding

| Period | Average Unemployment Rate |
|---|---:|
| 2019 | 9.4% |
| 2020 | 15.1% |

The dataset shows an increase of **5.7 percentage points** between the calculated 2019 and 2020 averages.

> This is a descriptive finding from the dataset and does not by itself establish that COVID-19 caused the entire increase.

### 📈 Task 4: Sales Prediction using Python

A Machine Learning project that predicts product sales based on advertising expenditure across different marketing channels.

#### Dataset Features

- TV Advertising
- Radio Advertising
- Newspaper Advertising
- Sales

#### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Jupyter Notebook

#### Machine Learning Model

- Linear Regression

#### Project Workflow

1. Load the advertising dataset.
2. Explore the dataset.
3. Remove unnecessary columns.
4. Check missing values and duplicate records.
5. Select features and target variable.
6. Split the data into training and testing sets.
7. Train the Linear Regression model.
8. Generate sales predictions.
9. Evaluate the model.
10. Analyze the relationship between advertising and sales.
